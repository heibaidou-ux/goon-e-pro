一、系统架构

ERP（店员用）→ HA (M710Q) → 物理设备（聚英继电器/485总线）

- HA地址：http://192.168.2.65:8123
- 登录：admin / admin123
- 当前集成：input_boolean（模拟开关）、input_number（音量）、Template（窗帘/功放状态）
- 暂无MQTT，暂无Modbus

HA REST API 调用
import os, requests
from dotenv import load_dotenv
load_dotenv()
HA_URL = os.getenv("HA_URL", "http://192.168.2.65:8123")
TOKEN = os.getenv("HA_TOKEN")

def toggle_light(entity_id):
    url = f"{HA_URL}/api/services/input_boolean/toggle"
    headers = {"Authorization": f"Bearer {TOKEN}", "Content-Type": "application/json"}
    return requests.post(url, json={"entity_id": entity_id}, headers=headers).json()

def get_state(entity_id):
    url = f"{HA_URL}/api/states/{entity_id}"
    headers = {"Authorization": f"Bearer {TOKEN}"}
    return requests.get(url, headers=headers).json()


开发原则
1. 先模拟再联调 — 所有代码在WSL上用虚拟input_boolean跑通
2. 每个功能一个脚本 — 单一职责，便于测试和移植
3. 配置文件与代码分离 — HA_URL/TOKEN写在.env中

HA API 端点
| 用途 | 方法 | URL |
| 获取所有状态 | GET | /api/states |
| 调用服务 | POST | /api/services/{domain}/{service} |
| 获取配置 | GET | /api/config |

3. 部署Mosquitto MQTT broker
4. 启动mqtt_bridge连接真实硬件
5. 联调聚英继电器485总线
