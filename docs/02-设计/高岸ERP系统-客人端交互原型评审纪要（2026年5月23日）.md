## 一、UI/交互意见

### 1.1 页面布局

| 意见 | 处理 |
|------|------|
| 页面应**贯穿式设计**，两边不留边距 | ✅ 采纳，统一修改 |
| 包间卡片也要贯穿式，底色统一 | ✅ 采纳 |
| 首页整体空间高度舒服，比预想中好 | 保留 |
| 中茶室页面太小需注意 | 提醒设计 |
| 配色需要统一，目前花里胡哨看着晕 | ⚠️ 后续优化 |

### 1.2 会员余额

- 会员余额280元不要单独占一行
- 改为**直接写在图标上**设计，如"280元"
- 验券开门功能

### 1.3 当前消费卡片

- 点击应进入"我的订单"
- 加右向小箭头暗示可点击

### 1.4 我的优惠券

- 保持现有设计，小功能点

| 灯开关 | 室内灯光控制 |

| 背景音乐 | 音量调节 |
| 蓝牙连接 | 手机连接音响 |

### 2.2 优惠券缺高德地图

优惠券页面缺少高德地图入口。

## 五、开发策略（关键决策）

### 核心结论：**先跑通，再优化**

| 原意见 | 决定 |
|--------|------|
| 在原型上继续抠细节 | ❌ **停止** |
| 快速出一个真实可用版本 | ✅ **优先** |
| 商城功能 | ✅ 可以先不做，用现有的 |
| 锁/485/开关连线 | 店开业前全部连好 |
| 真实环境测试 | 拿着APP在店里走一遍，问题自然暴露 |

### 理由

1. 现在靠想象提意见效率低
2. 原型质量已相当不错，不要再花更多时间
3. **有AI辅助开发，改东西很快**，成本低
4. 真实跑起来才能发现"不开门""反应慢"等真问题
