# 高岸ERP系统-盈隆店IoT接线实施指南（简版）

**版本**：V1.4  
**日期**：2026年5月18日  
**参考详版**：高岸ERP系统-盈隆店IoT接线实施指南（V1.4）

**V1.4核心变更**：
- 增补35mm DIN工业导轨安装规范：导轨从左至右排列为断路器→HDR-15-24→DAM0808D→4口集线器，线缆走下槽
- 锁死屏蔽层接地细则：干线屏蔽层仅在机柜端拧入地线端子排，房间端剪断悬空缠死

## 1. 总体需求与设计思路

### 设计目标

盈隆店有**5个房间**（大会议室、中茶室A/B、大茶室C、展厅），要实现：

| 需求 | 怎么实现 |
|------|---------|
| 每个房间独立播放背景音乐 | 每个房间装一台**itc T-6715网络广播终端**（吊顶电箱内），HA主机通过IP网络推流 |
| 客人可以连蓝牙放自己音乐 | 吊顶电箱内装**隐藏式蓝牙音频模块**，3.5mm短线直连T-6715 LINE IN |
| 手机控制灯光/空调/窗帘 | **RS485总线**连接继电器模块，HA通过485控制 |
| 远程下发门锁密码 | **通通锁**智能门锁 + **G2网关**（走廊居中） |
| 前台管理订单结束后自动关灯关空调 | HA主机联动继电器CH通道，**硬切断220V强电**，零待机功耗 |

### 核心设计原则

1. **分布式IP音频**——每个房间T-6715独立解码，HA通过网络推流
2. **双层485星型拓扑**——机柜HUB4858→各房间，房内4口集线器星型分线至各设备
3. **强弱电分离**——弱电线与220V强电线**严禁共管**
4. **24V供电本地化**——各房间本地HDR-15-24给继电器本体24x7供电
5. **强电总控**——220V经继电器CH通道硬切T-6715/蓝牙/窗帘/照明
6. **DIN导轨标准化**——吊顶电箱内全部组件卡入35mm导轨，从左至右标准排列
7. **屏蔽层规矩**——干线屏蔽仅机柜端接地，房间端剪断悬空

## 2. 系统拓扑

### 2.1 信号层拓扑（485通讯路径）

```
工作间机柜
  │
  └── 聚英 HUB4858（8路隔离集线器）
       ├── OUT1 ── RVVP黄/白 ──→ 大会议室 ──→ 房内4口集线器
       │                                               ├── OUT1 → 继电器(Slave ID=01)
       │                                               ├── OUT2 → 空调面板(Slave ID=21)
       │                                               ├── OUT3 → 窗帘电机(Slave ID=31)
       │                                               └── OUT4 → 场景面板(Slave ID=11)
       ├── OUT2 ── RVVP黄/白 ──→ 中茶室A  ──→ 房内4口集线器（继电器02、空调22、窗帘32、面板12）
       ├── OUT3 ── RVVP黄/白 ──→ 中茶室B  ──→ 房内4口集线器（继电器03、空调23、窗帘33、面板13）
       ├── OUT4 ── RVVP黄/白 ──→ 大茶室C  ──→ 房内4口集线器（继电器04、空调24、窗帘34、面板14）
       ├── OUT5 ── RVVP黄/白 ──→ 展厅     ──→ 房内4口集线器（继电器05，展厅无面板/空调/窗帘）
       └── OUT6 ── RVVP黄/白 ──→ 工作间
```

> **注意**：Slave ID按功能域分三段：继电器01-05、场景面板11-14、空调21-24、窗帘31-34，同功能域ID错开一个房间间隔，便于调试时分房间独立排查。

### 2.2 供电层拓扑（220V分配路径）

```
全屋强电总闸
  │
  │                              吊顶电箱35mm DIN导轨
  │                              ┌──────────────────────────────────┐
  ├── 常开回路 ──→ 220V空开 ──→ HDR-15-24 ──→ 继电器模块本体24V   │
  │                              │                                   │
  │                              │（注：HDR-15-24接线端子在导轨下方） │
  ├── 受控回路 ──→ 空开输出 ──→ 继电器CH COM端                    │
  │                              ├── CH1: 双位插排上口(T-6715砖头)   │
  │                              ├── CH2: 双位插排下口(蓝牙模块)     │
  │                              ├── CH3: 窗帘电机                   │
  │                              ├── CH4-5: 照明回路                 │
  │                              └── CH6-8: 排风/茶炉/预留           │
  └── 走廊G2网关 ──→ BV 3×2.5mm² ──→ 86型USB插座
```

### 3.3 485芯线颜色定义（V1.4）

| 颜色 | 信号 | 操作说明 |
|------|------|---------|

### 3.4 屏蔽层与终端电阻工规（V1.4新增）

**屏蔽层处理：**
- **机柜端**：全店所有房间的干线屏蔽层金属网统一拧成一束，用冷压端子压接后锁入机柜地线端子排（PE/GND）
- **房间端**：干线到达吊顶电箱后，屏蔽层金属网剪断至根部，立即用绝缘胶布缠绕3-5圈封死，绝对禁止接触房内任何端子或设备外壳
- 房间内部的短途分支线（4口集线器→各设备）无需接屏蔽层

**终端电阻规则：**
- 干线长度＜50米：**不加终端电阻**（双层集线器自带阻抗匹配，足以抵抗吊顶干扰）
- 干线长度≥50米：在房内4口485集线器的INPUT端子排上，在A+/D+与B-/D-之间**并联1个120Ω 1/4W电阻**（可插拔端子式）
- 电阻安装位置：4口集线器输入端，非设备端

## 4. 吊顶电箱导轨化装配（V1.4核心）

### 4.1 35mm DIN导轨排列（从左至右，不可调换顺序）

```
┌─────────────────────────────────────────────────────────────────┐
│  吊顶弱电电箱（≥400×400mm）                                      │
│                                                                  │
│  ┌──────┐  ┌─────────┐  ┌────────────┐  ┌──────────────┐       │
│  │ 空开  │  │HDR-15-24│  │ DAM0808D   │  │ 4口485集线器 │       │
│  │1P 10A │  │24V 15W  │  │8路继电器   │  │(房内)        │       │
│  │220V入 │  │AC→DC    │  │Slave ID=01 │  │INPUT←485干线│       │
│  └──────┘  └─────────┘  └────┬───────┘  └──────┬──────────┘       │
│  ↑          ↑                ↑                  ↑                 │
│  └──────────┴────────────────┴──────────────────┴── 35mm DIN导轨  │
│                                                                  │
│  ═══════════════════════════════════════════════════════════════  │
│  ▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓  线缆线槽  ▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓  │
│                                                                  │
│  [双位插排] (吊挂在电箱侧壁，非导轨上)                              │
│   上口: T-6715台达砖头适配器 ← CH1控                               │
│   下口: 蓝牙模块适配器         ← CH2控                               │
│                                                                  │
│  T-6715 (吊挂在电箱剩余空间，非导轨上)                               │
│   220V适配器→插双位插排上口                                         │
│   LINE IN→蓝牙音频(3.5mm短线)                                      │
│   SPK OUT→吸顶音箱                                                 │
└─────────────────────────────────────────────────────────────────┘
```

**安装规范：**
1. 35mm标准铝导轨用M4螺丝固定在电箱底板，长度≥300mm，水平安装
2. 组件从左至右按"断路器→HDR-15-24→DAM0808D→4口集线器"顺序卡入导轨，不得调换
3. 导轨正下方安装PVC线槽（宽≥40mm），所有接线统一从线槽走，严禁飞线
4. 双位插排和T-6715不卡导轨，用螺丝固定在电箱侧壁或底板剩余空间
5. 通电前用万用表确认：空开输出端→HDR-15-24输入端，HDR-15-24输出端→继电器24V供电端

### 4.2 强电分路

| 路径 | 说明 |
|------|------|
| 常开回路 | 220V进空开→HDR-15-24→24V DC给继电器本体（24x7不断电） |
| 受控回路 | 空开输出→继电器CH COM端→各CH通断控制设备 |
| 双位插排 | 接在空出输出端（经CH1-CH2控）或常开回路（取决于是否需要订单联动） |

CH1-CH2建议接在受控回路（继电器切），实现订单结束自动断电。

## 5. 走线与寻址要点

1. **485红/黑剪断**：机柜端和房间端都把红/黑芯线剪断、套热缩管，严禁接触任何端子
2. **屏蔽层规矩**：干线屏蔽仅机柜端接地，房间端剪断缠死；房内分支不接屏蔽
3. **终端电阻**：干线＜50米不加，≥50米在4口集线器INPUT端A+/B-并联120Ω
4. **强弱电分开**：弱电线单独走PVC管，严禁与220V共管
5. **DIN导轨标准**：空开→HDR-15-24→DAM0808D→4口集线器，正下方线槽走线
6. **Slave ID错开**：继电器01-05、面板11-14、空调21-24、窗帘31-34，同功能域隔一个房间
7. **留余量**：每根线两端各留30-50cm
8. **管径**：大会议室φ50，其余φ32，摄像头单独走管
9. **音箱线**：房间内T-6715直接→吸顶音箱，不经过机柜
10. **走廊**：居中预留86型USB插座给G2网关；走廊尽头和玄关各预留1根网线给PoE摄像头
11. **继电器负载**：每个CH通道不得超出10A，严禁接入电热水壶/大功率空调柜机
