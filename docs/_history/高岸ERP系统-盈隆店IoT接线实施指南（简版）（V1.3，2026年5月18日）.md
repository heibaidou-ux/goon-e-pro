# 高岸ERP系统-盈隆店IoT接线实施指南（简版）

**版本**：V1.3  
**日期**：2026年5月18日  
**参考详版**：高岸ERP系统-盈隆店IoT接线实施指南（V1.3）

**V1.3核心变更**：
- 信号与供电彻底剥离：485线红/黑芯线两端剪断悬空，不再传输24V电源
- 双层485星型拓扑：机柜HUB4858→各房间→房内4口485集线器→各设备独立拉线
- 强电总控闭环：220V分常开回路（HDR-15-24给继电器本体24x7供电）和受控回路（继电器CH→双位插排→T-6715/蓝牙）

## 1. 总体需求与设计思路

### 设计目标

盈隆店有**5个房间**（大会议室、中茶室A/B、大茶室C、展厅），要实现：

| 需求 | 怎么实现 |
|------|---------|
| 每个房间独立播放背景音乐 | 每个房间装一台**itc T-6715网络广播终端**（吊顶电箱内），HA主机通过IP网络推流 |
| 客人可以连蓝牙放自己音乐 | 吊顶电箱内装**隐藏式蓝牙音频模块**（无墙面面板），3.5mm短线直连T-6715 LINE IN |
| 手机控制灯光/空调/窗帘 | **RS485总线**连接继电器模块，HA通过485控制 |
| 远程下发门锁密码 | **通通锁**智能门锁 + **G2网关**（走廊居中） |
| 前台管理订单结束后自动关灯关空调 | HA主机联动继电器CH通道，**硬切断220V强电**，零待机功耗 |

### 核心设计原则

1. **分布式IP音频**——每个房间T-6715独立解码，HA通过网络推流，不拉长模拟音频线
2. **双层485星型拓扑**——机柜HUB4858放射至各房间（仅信号），房内4口485集线器星型分线至各设备
3. **强弱电分离**——弱电线（网线/485/音频）与220V强电线**严禁共管**
4. **24V供电本地化**——取消远程送电，各房间本地HDR-15-24给继电器本体24x7供电
5. **强电总控**——220V经继电器CH通道硬切T-6715/蓝牙/窗帘/照明，待机零功耗
6. **工作间集中**——交换机、HA主机、HUB4858、无线话筒接收机全部放在工作间机柜

## 2. 系统拓扑

### 2.1 信号层拓扑（485通讯路径）

```
工作间机柜
  │
  └── 聚英 HUB4858（8路隔离集线器）
       ├── OUT1 ── RVVP黄/白 ──→ 大会议室 ──→ 房内4口集线器 ──→ 继电器/空调/窗帘/面板
       ├── OUT2 ── RVVP黄/白 ──→ 中茶室A  ──→ 房内4口集线器 ──→ 同上
       ├── OUT3 ── RVVP黄/白 ──→ 中茶室B  ──→ 房内4口集线器 ──→ 同上
       ├── OUT4 ── RVVP黄/白 ──→ 大茶室C  ──→ 房内4口集线器 ──→ 同上
       ├── OUT5 ── RVVP黄/白 ──→ 展厅     ──→ 房内4口集线器 ──→ 同上
       ├── OUT6 ── RVVP黄/白 ──→ 工作间
       └── 预留3根备用线至天花板理线槽
```

> **V1.3变更**：485线RVVP的红/黑芯线在机柜端和房间端均剪断悬空（套绝缘热缩管），**严禁传输24V电源**。24V供电改为各房间本地HDR-15-24取电。

### 2.2 供电层拓扑（220V分配路径）

```
全屋强电总闸
  │
  ├── 常开回路 ──→ 各房间HDR-15-24(15W) ──→ 继电器模块本体（24x7不断电）
  │
  ├── 受控回路 ──→ 继电器CH COM端
  │                  ├── CH1: T-6715砖头适配器 → 双位插排上口
  │                  ├── CH2: 蓝牙模块适配器 → 双位插排下口
  │                  ├── CH3: 窗帘电机强电
  │                  ├── CH4-5: 照明回路
  │                  └── CH6-8: 排风/茶炉/预留
  │
  └── 走廊G2网关供电 ──→ BV 3×2.5mm² ──→ 86型USB插座（常开）
```

### 2.3 音频链路

蓝牙音频模块隐藏安装在吊顶电箱内（不再使用86墙面面板），**无需预埋蓝牙音频线**，仅在电箱内用3.5mm短线对插即可。音箱线（T-6715→吸顶音箱）仍需电工预埋走管。

蓝牙模块和T-6715的220V适配器均插在双位插排上，受继电器CH1-CH2控制，订单结束HA自动断电（防蹭连、防串号、零待机功耗）。

### 3.5 走线要点

1. **485红/黑剪断**：机柜端和房间端都把红/黑芯线剪断悬空，套绝缘热缩管，严禁接触任何端子
2. **房内485星型**：房内各485设备向4口集线器独立拉线，免并线、免手拉手
3. **强弱电分开**：弱电线必须单独走PVC弱电管，严禁与220V强电线共管
4. **留余量**：每根线两端各留30-50cm富余
5. **管径选择**（网线、485线可同管）：
   - 大会议室（4根：设备网+AP×2+485）：1根φ50管
   - 其他房间（3根：设备网+AP+485）：1根φ32管
   - 摄像头网线单独走管，与弱电管同路径
6. **音箱线不经过机柜**：在房间内直接走T-6715→吸顶音箱
7. **走廊预留**：走廊居中位置预留1个86型USB插座（给G2网关供电）；走廊尽头和玄关各预留1根网线（给PoE摄像头，与弱电管同管）
8. **继电器负载限制**：每个CH通道不得超出10A，严禁接入电热水壶/大功率空调柜机等感性大负载
