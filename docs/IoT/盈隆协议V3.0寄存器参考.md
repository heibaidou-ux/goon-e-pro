# 盈隆 Protocol V3.0 — Register Reference

Based on official protocol document `3497058474485通讯协议.pdf` V3.0.

## Key Protocol Quirks

- **2-byte data length**: 盈隆 response frames have 2-byte length field (not standard 1-byte). 
  - Example: `3C 03 00 02 00 19 14 4B` — `00 02` = 2 data bytes
  - Configurable to 1-byte via register 0x0023 BIT7
- **Inter-command gap**: ≥50ms
- **Serial**: 9600 8N1 (default)

## Device Default Addresses

| Device | Default | Range | Address Register |
|--------|---------|-------|-----------------|
| Switch panel (开关面板) | **0x02** | 1-42 | **0x1000** |
| Thermostat (温控器) | **0x3C** (60) | 1-60 | **0x0020** |
| Card switch (插卡取电) | **0x1E** (30) | 1-254 | **0x0200** |
| Broadcast | 0xFF | — | write-only |

## Command Codes

| Code | Operation |
|------|-----------|
| 03H | Read holding registers |
| 06H | Write single register |
| 10H | Write multiple registers |
| 83H | FC03 error response |
| 86H | FC06 error response |

Error codes: 01=CRC, 02=operation, 03=read-only, 04=register not found, 05=invalid op, 06=write-protected

## Frame Format

Request: `[addr 1B][func 1B][reg_addr 2B][data/count nB][CRC 2B]`
Response: `[addr 1B][func 1B][**data_len 2B**][data nB][CRC 2B]`

## Switch Panel Registers (0x1000~0x1FFF)

| Addr | R/W | Description |
|------|:---:|-------------|
| 0x1000 | R/W | **Panel address**. Default 0x02, range 1-42. Max 42 (keys invalid beyond). |
| 0x1003 | R/W | **Work mode config** (see bit definitions below) |
| 0x1007 | R/W | Relay control (only when desynced from LEDs, via 1003 BIT0) |
| 0x1008 | R/W | **LED/relay control**: BIT0-5=K1-K6 LEDs, BIT8=backlight. Writing LED bits auto-toggles relay. |
| 0x1009 | R/W | Key1-4→relay output mapping (4 bits per key) |
| 0x100A | R/W | Key5-6→relay output mapping |
| 0x100B | R/W | **Key + relay status**: BIT0-5=key1-6 pressed(=1), BIT8-13=relay1-6 ON(=1). In poll mode, key bits auto-clear after 2s or after host read. |
| 0x100E | WO | Factory reset (write 0x0000) |
| 0x100F | WO | Save config to EEPROM (write 0x00FE, or auto-save after 30s) |
| 0x1310-1F | RO | Key K1-K16 state: 0=off, 1=on, 2=long-press, FF=stuck. Cleared after read. |

### 0x1003 Bit Definitions

| Bit | Function | Notes |
|:---:|----------|-------|
| 0 | Demo mode | 1=local control only (showroom demo) |
| 1 | RCU mode | 1=LEDs controlled by RCU host |
| 2 | Active-send | 1=keys auto-send on press; 0=poll mode |
| 3 | Sensor enable | 1=enable IR/touch sensor |
| 4 | Delay-off LED | 1=backlight off after 15s idle |
| 5 | Release-send | 1=also send on key release (requires bit2=1) |
| 6 | Key lock | 1=panel keys disabled, host unlock only |

### Active-send Format (when 1003 BIT2=1)
Press: `02 03 00 02 08 02 62 38` → K2 pressed
Release: `02 03 00 02 08 00 E3 F9` → K2 released (byte 6 = 0)

Format: `[addr][0x03][len 2B][abs_key][key_num][CRC]`

## Thermostat Registers (0x0000~0x0FFF)

| Addr | R/W | Description |
|------|:---:|-------------|
| 0x0020 | R/W | **Device address**. Default 0x3C, range 1-60. |
| 0x0021 | R/W | Config: BIT7=1-byte len, BIT2=remote-lock, BIT3=disable |
| 0x0022 | R/W | Config: BIT0-1=fan-off-on-temp, BIT2-3=power-on-state, BIT4=active-send, BIT5=°C/°F, BIT6=2/4-pipe, BIT7=backlight-half |
| 0x0023 | R/W | Temp calibration (-9.5~+9.5°C). Data 0-38, 19=0°, +1=+0.5°C. Default 15(-2.0°C). |
| 0x0028 | R/W | Temp sensor: BIT0=0 internal, =1 external |
| 0x0029 | R/W | Setpoint shared: BIT0=0 separate(0x36 cool/0x4C vent/0x4D heat), =1 use 0x0036 only |
| 0x002D | R/W | Temp max: 5-35°C, default 30°C |
| 0x002E | R/W | Temp min: 5-35°C, default 16°C |
| 0x002F | R/W | Mode set: BIT7=4-pipe, BIT0-3=00 cool+heat+vent, 01=cool-only, 02=heat-only, 03=auto |
| 0x0030 | RO | **Status**: BIT0-1=fan(00/01/02/03=lo/mid/hi/off), BIT2=cool-valve, BIT3=heat-valve, BIT4-5=mode(00/01/02=cool/heat/vent), BIT7=power(0=off,1=on) |
| 0x0031 | R/W | **Mode**: 00=cool, 01=heat, 02=vent |
| 0x0032 | R/W | **Fan**: 00=low, 01=mid, 02=high, 03=off, 04=auto. Also 5-step custom. |
| 0x0033 | RO | **Room temp °C**. Example: `3C 03 00 33 00 01 70 E8` |
| 0x0035/4D | R/W | **Heat setpoint °C** (0x4D and 0x0035 are same register) |
| 0x0036 | R/W | **Cool setpoint °C** |
| 0x0039 | R/W | **Power**: 00=off, 01=on |
| 0x004C | R/W | Vent setpoint °C |

## Address Change Examples

### Switch panel: 0x02 → 0x01
```
02 06 10 00 00 01 4C F9   → write addr register 0x1000 = 1
```
Then save: `02 06 10 0F 00 FE 3C BA` or wait 30s.

### Broadcast all panels to address 1
```
FF 06 10 00 00 01 59 14
```

### Thermostat: 0x3C → 0x01
```
3C 06 00 20 00 01 4D 2D
```

### Broadcast all thermostats: 0x01
```
FF 06 00 20 00 01 9C 2E
```

### Factory reset switch panel
```
FF 06 10 0E 00 00 F9 17   → broadcast
```
Needs save command or 30s auto-save.

## Scan Probe Strategy

When scanning, use the correct register for each device type:
- **Switch panel**: FC03 read **0x1000** (address register, always present)
- **Thermostat**: FC03 read **0x0020** (address register, always present)
- **Card switch**: FC03 read **0x0200** (address register, always present)

**Never probe 0x0000 or 0x0002** — these registers don't exist on any 盈隆 device and will produce false "no response" results.

## CRC16

Standard Modbus CRC16: polynomial 0xA001, init 0xFFFF, little-endian.
