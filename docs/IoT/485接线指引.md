# 盈隆RS485布线指引（给电工）

## 线色定义

找出四芯线中两两双绞的线对，例如红蓝一组、黄绿一组：

| 颜色 | 接什么 |
|:----:|:------:|
| **黄** | **A（D+）** |
| **绿** | **B（D-）** |
| **蓝** | **GND（PB）** |
| **红** | **12V**（仅需供电设备） |

## 设备接线分类

**（1）自供电设备（空调面板）和无需供电设备（485集线器）：**

黄 – A / 绿 – B / 蓝 – GND（空调面板这条线不接）/ 红 – 空着

**（2）低压供电设备（继电器、开关面板、窗帘电机）：**

黄 – A / 绿 – B / 蓝 – GND / 红 – 12V

## 屏蔽网处理

只在电脑机柜端剥出屏蔽网接地（螺丝拧到机柜接地排）。
经过集线器和末端设备一概剪断包好，**不能接地**。
面板间跳线、窗帘电机间跳线的屏蔽网可以连通，但不能接地，也不能碰到其他线。
