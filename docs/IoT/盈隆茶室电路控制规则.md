   132|## 五、虚拟总电源控制规则（HA软件实现）
   133|
   134|> 无需额外总电源硬件继电器，由HA通过8路485继电器+温控面板Modbus实现。
   135|
   136|### 5.1 虚拟总电源开关
   137|在HA中为每个房间创建一个`input_boolean`虚拟开关作为总电源。
   138|
   139|### 5.2 虚拟总电源"关闭"时的操作
   140|HA执行以下动作：
   141|- 关闭该房间8路485继电器的**所有灯/风扇通道**
   142|- 关闭该房间功放通道
   143|- 发送Modbus指令给该房间温控面板 → 关闭空调
   144|- **小茶室换气扇通道（CH3）不关闭**
   145|
   146|### 5.3 虚拟总电源"开启"时的操作
   147|HA执行以下动作：
   148|- 恢复该房间各灯光/风扇通道到之前状态
   149|- 恢复功放通道
   150|- 温控面板保持上次的温度设定（不自动开空调）
   151|
   152|### 5.4 小茶室换气扇软件逻辑
   153|```
   154|订单结束后 → HA保持换气扇开启15分钟 → 自动关闭
   155|（不受总电源开关影响）
   156|```
   157|
   158|### 5.5 空调共用规则
   159|
   160|#### 5.5.1 物理控制
   161|空调的开关/温度/模式由**盈隆RS485温控面板**（地址0x3C）控制，通过485总线发Modbus指令。
   162|
   163|#### 5.5.2 空调功率控制
   164|空调电源由HA通过Modbus控制温控面板实现通断。虚拟总电源关闭时，HA发Modbus指令关空调。
   165|
   166|#### 5.5.3 空调共用规则
   167|
   168|| 共用组 | 包含房间 | 关机条件 |
   169||--------|---------|---------|
   170|| **AC组1** | 小茶室 + 会议室 | 两个房间都为空（无订单）或客服离店，才真正关闭 |
   171|| **AC组2** | 中茶室 + 工作间 | 两个房间都为空（无订单）或客服离店，才真正关闭 |
   172|
   173|逻辑：
   174|```
   175|IF AC组1的两个房间都为空（无进行中订单）AND 客服已离店：
   176|    关闭空调1电源
   177|ELSE IF 任一房间有订单：
   178|    保持空调1通电（由温控面板控制开关和温度）
   179|ENDIF
   180|
   181|IF AC组2的两个房间都为空（无进行中订单）AND 客服已离店：
   182|    关闭空调2电源
   183|ELSE IF 任一房间有订单：
   184|    保持空调2通电（由温控面板控制开关和温度）
   185|ENDIF
   186|```
   187|
   188|### 6.4 空调不占用继电器通道
   189|空调电源控制由**额外的空调专用继电器**或总电源继电器控制，不占用8路485继电器的通道。
   190|
   191|**建议采用以下方案：**
   192|- 每个共用组（AC组1、AC组2）各用一个**独立的16A继电器**控制空凋总电源
   193|- 这两个空调继电器由HA根据订单状态自动控制
   194|- 不纳入任何房间的总电源继电器管理范围

   332|## 十一、总电源接线逻辑
   333|
   334|```
   335|市电进线
   336|  │
   337|  ├── 各房间ESP32 + 485集线器 ── 常电（不断电）
   338|  │
   339|  ├── 8路485继电器(会议室) → 筒灯1/2、吊灯、风扇1/2/3、功放
   340|  ├── 8路485继电器(小茶室) → 吊灯、筒灯、换气扇、风扇、功放×2（含展厅）
   341|  ├── 8路485继电器(中茶室) → 吊灯、筒灯、背景灯、风扇、功放
   342|  └── 8路485继电器(大茶室) → 吊灯、筒灯、背景灯、风扇、功放
   343|
   344|485温控面板通过485总线与ESP32通信，每个房间1个。
   345|窗帘电机通过485总线与ESP32通信。
   346|
   347|虚拟总电源由HA统一控制各通道开关实现。
   348|小茶室换气扇由软件逻辑确保订单结束后继续运行。
   349|空调由HA在"总电源关"时通过Modbus关闭温控面板实现。
   350|```
   351|
   352|> 设计原则：ESP32和485总线常电，确保远程控制不断。所有设备通断由8路485继电器+HA软件逻辑控制。

   356|## 十二、关键设计决策记录
   357|
   358|1. **灯全开/全关是软件功能** — 不占用继电器物理通道，由HA同时控制所有灯通道
   359|2. **窗帘开/关是软件功能** — 不占用继电器物理通道，HA通过覆盖API控制电机
   360|3. **展厅功放借用小茶室CH6** — 会议室继电器已满7路，移至小茶室备用通道
   361|4. **小茶室换气扇接继电器CH3** — 不由总电源切断，由HA软件逻辑保持订单结束后继续运行15分钟后自关
   362|5. **虚拟总电源** — 无硬件总电源继电器，由HA通过8路继电器+Modbus温控实现
   363|6. **空调共用逻辑** — AC组1（小茶室+会议室）和AC组2（中茶室+工作间）的电源控制由HA根据订单状态自动决策，通过Modbus控制温控面板
   364|
